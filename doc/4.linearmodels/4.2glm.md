# 4.2 Logistic Regression

## Concept

Logistic Regression 是一个在 $$0-1$$ 之间的连续函数。这个连续函数表示的是可能性。小于 0.5 的时候类别归为 0，大于 0.5 的时候类别归为 1。

## Formula

**Sigmoid function**: $$\phi (z) = \frac{1}{1+e^{-z}}$$

Logistic regression formula: $$h_{\theta}(X) = P(y=1|X) = \frac{1}{1+e^{-\theta^TX}}$$，这里面认为 $$X$$ 和 log odds 之间呈线性关系，所以 $$\theta^TX$$ 拟合的其实是 log odds。

$$Odds=\frac{P(y=1|X)}{P(y=0|X)}$$，表示的是 $$y=1$$ 时的概率比上 $$y=0$$ 时的概率。

$$log\ odds = log\ \frac{P(y=1|X)}{P(y=0|X)} = -\theta^TX$$

## Application

Logistic Regression 可以做简单的情感正负分析。比如做评论分析的时候，一个句子的情感就是这个句子里包含的关键词的情感的组合。

$$\theta^TX$$ 这里面的每一个 $$x$$ 代表的是这个词出现的频率 (TF-IDF: Term Frequency - Inverse Document Frequency)，而每一个 $$\theta$$ 代表的就是这个词的权重。

然后我们把这个 $$\theta^TX$$ 带入 logistic regression 的模型 $$P(y=1|X) = \frac{1}{1+e^{-\theta^TX}}$$ 中去训练，训练的就是每一个词它的情感的权重 $$\theta$$。

## Loss Function

$$
\begin{eqnarray*}
J(\theta) &=& -\frac{1}{N}[\Sigma_{i=1}^N \Sigma_{j=0}^1 I(y^{(i)} = j)\ log\ P(y^{(i)}=j|X^{(i)}; \theta)] \\
&=& -\frac{1}{N}[\Sigma_{i=1}^N\ y^{(i)}\ log\ (h_{\theta}(x^{(i)})) + (1-y^{(i)})\ log (1 - h_{\theta}(x^{(i)}))
\end{eqnarray*}
$$

有了 loss function 以后就可以用比如 Gradient Descent 之类的方法来求最优值了。

我们还可以对 logistics regression 的公式进行变形。

首先是当 $$y = 1$$ 的时候：

$$
\begin{eqnarray*}
P(y=1|X) &=& \frac{1}{1+e^{-\theta^TX}} \\
&=& \frac{e^{\theta^TX}}{e^{\theta^TX}(1+e^{-\theta^TX})} \\
&=& \frac{e^{\theta^TX}}{e^{\theta^TX} + 1}
\end{eqnarray*}
$$

然后是当 $$y = 0$$ 的时候：

$$
\begin{eqnarray*}
P(y=0|X) &=& 1- \frac{e^{\theta^TX}}{e^{\theta^TX} + 1} \\
&=& \frac{1}{e^{\theta^TX}+1} \\
&=& \frac{1}{1 + e^{\theta^TX}}
\end{eqnarray*}
$$

## Softmax

在进行变换之后，我们可以把这个公式扩展到多分类的问题上面：

**Softmax Regression**: $$P(y^{(i)} = k|X) = \frac{exp({\theta_k^Tx^{(i)}})}{\Sigma_{j=1}^K exp({\theta_j^Tx^{(i)}}) }$$
