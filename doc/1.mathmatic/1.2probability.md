# 1.2 Probability

## Concept

**Some Laws:**

* Non-negativity: $$P(A) \ge 0$$
* Additivity: $$P(A \cup B) = P(A) + P(B)$$ if A and B are two disjoint events
* Normalization: $$P(\Omega) = 1$$

## Conditional Probability:

当事件B发生时，事件A发生的概率：

$$
P(A \cap B) = P(A|B)P(B)
\ \ \ \ \ \ \Rightarrow\ \ \ \ \ \ \
P(A|B) = \frac{P(A \cap B)}{P(B)}
$$

**Monty Hall problem:**

假设桌上有A, B, C 3个盒子，其中1个盒子中有奖品。我们选择其中一个：盒子A，我们猜它可能是藏有奖品的盒子。然后打开另外两个盒子中的一个：盒子B，发现它没有奖品。现在我们有一个选择权，可以坚持选择盒子A，也可以更换盒子C。那如果想要拿到奖品现在我们是否应该更换选择?

At begining: $$P(A) = \frac{1}{3} \ \ \ ,\ \ \ P(B) + P(C) = \frac{2}{3}$$

After we open the Box B, we notice that $$P(B) = 0$$, now $$P(C)=\frac{2}{3}​$$. Thus we should change our choice to Box C.

## Independence

**Event A and B are independent:**

$$
P(A|B) = P(A) \ ,\ P(B|A) = P(B)
\ \ \ \ \Rightarrow \ \ \ \ \
P(A \cap B) = P(A)P(B)
$$

* If given an additional  event C with $$P(C) > 0$$:

$$
P(A \cap B|C) = P(A|C)P(B|C)
\ ,\ \ 
P(A|B \cap C) = P(A|C)
$$

**Event A and B are NOT independent:**

$$
P(A \cap B) = P(A|B)P(B) = P(B|A)P(A)
$$

* Thus, we can get the Bayes' Rule:

$$
P(A|B) = \frac{P(B|A)P(A)}{P(B)}
$$

## Binomial Probabilities

The probability of $$n$$-toss sequence that contatins $$k$$ heads is:

$$
p(k) = \left( \begin{array}{}n \\k \end{array} \right)p^k(1-p)^{n-k}
$$

where $$\left( \begin{array}{}n \\k \end{array} \right)$$ (called $$n$$ choose $$k$$) $$=$$ number of distinct $$n$$-toss sequences that contain $$k$$ heads.

$$
\left( \begin{array}{}n \\k \end{array} \right) = \frac{n!}{k!(n-k)!}
\ \ \ \ \ \ \ \ \ for\
k = 0,1,...,n
$$

The number $$\left( \begin{array}{}n \\k \end{array} \right)$$ are known as the **binomial coefficients**; the probability $$p(k)$$ are known as the **binomial probabilities**.

## Expected Value & Variance

**Expected Value**

$$
E[X] = \Sigma_x\ x \cdot p_X(x)
\ , \ \ \ \ 
E[g(x)]=\Sigma_x g(x) \cdot p_X(x)
$$

$$p_X(x)$$ 就是PMF (Probability Mass Function), 而考虑到概率权重的Mean就是Expected value.

**Variance**

$$
var(X) = E[(X - E[x])^2]
\ \ \ \ \ \Rightarrow \ \ \ \ 
var(X) = \Sigma(x - E[X])^2p_X(x)
$$

**Standard Deviation**

$$
\sigma_X = \sqrt{\Sigma(x - E[X])^2p_X(x)}
$$

## Covariance

$$
Cov(X,Y) = E[(X-E[X])(Y-E[Y])] = E[XY]-E[X]E[Y]
$$

* If no correlation $$\Rightarrow$$ Covariance 趋近于0
* If positive correlation $$\Rightarrow$$ $$Cov > 0$$
* If negative correlation $$\Rightarrow$$ $$Cov < 0$$

但以上推导反过来是不成立的

## Joint Probability of More than One Random Variables

Then the following statement is given:

$$
p_{(X,Y,Z)} = P(X = x, Y = y, Z = z)
$$

If we want to calculate the **Marginal Probability**:

$$
p_X(x)=\Sigma_y\Sigma_zp_{X,Y,Z}(x,y,z)
$$

If we want to calculate the **Joint Probability of X and Y:**

$$
p_{X,Y}(x,y)=\Sigma_zp_{X,Y,Z}(x,y,z)
$$

And we can also calculate the **Expected Value:**

$$
E[g(X,Y,Z)] = \Sigma_{x,y,z}g(x,y,z) \cdot p_{X,Y,Z}(x,y,z)
$$

## Probability Density Function (PDF)

概率密度函数 (Probability Density Function)是指将某个事件的概率表示成的一个连续函数 (Continuous function)

不同的PDF代表着不同的分布方式，很多其实都是Exponential distribution，较为常见的有：

**1. Nomal (Gaussian) Distribution**

正态分布：均值变大分布向右平移；variance 变大则曲线更平缓。

**2. Binomial Distribution (Pascal's triangle)**

离散分布中有一种叫做**Bernoulli distribution**：

$$
f(k;p) = \left\{
\begin{array}{ccc}
p & if\ k=1\\
1-p & if\ k=0
\end{array} \right.
$$

在n次bernoulli分布后，所有的特定组合的概率就形成了Binomial Distribution

**3. Multinomial Distribution**

和Binomial类似，唯一不同的就是不是0, 1的选择，可以有更多选项。

**4. Gamma Distribution**

Gamma function是阶乘的扩展，可以找到连续数值的的阶乘。

**5. Beta Distribution**

Beta分布是在0 \~ 1之间的分布，可以表示很多种类型的分布，但都在0 \~ 1之间。Beta分布也是基于Gamma分布的。

**6. Poisson Distribution**

$$f(k;\lambda) = Pr(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$$

$$P(k=0$$ overflow floods in 100 yrs$$)=\frac{1^0 e^{-1}}{0!}=0.368$$

$$\lambda$$ 等于多少的时候，分布图上最大的值就是多少。

**7. Log-Normal Distribution** (不太常用)

$$X=e^{\mu + \sigma Z}$$ with $$Z$$ a standard normal variable.
