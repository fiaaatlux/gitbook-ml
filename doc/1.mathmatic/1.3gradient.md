# 1.3 Gradient Descent

## Notation

Cardinality: $$|D| = N$$, 这个符号如果说里面是一个值，就代表绝对值；如果里面是一组数据，就代表这组数据的个数。

$$R^n$$: 表示一个 $$n$$ 维 vector，如果 $$n=1$$ 就是一个scalar.

## Linear Function

The simplist **linear function** looks like: $$h_{\theta}(x^{(i)}) = \theta_0 x_0 + \theta_1 x_1$$ , with $$x_0$$ always equal to 1.

If we treat $$\theta$$ and $$x$$ as vectors: $$\theta^T = (\theta_0,\ \theta_1) \ , \ x = \left( \begin{array}{ccc}x_0 \\x_1 \end{array} \right)$$, we can make a more **generalized function:**

$$
h_{\theta}(x^{(i)}) = \theta^T x \ , \ \ with\ \theta \in R^{n+1} \ and \ x \in R^{n+1}
$$

**Loss function:** $$J(\theta) = \frac{1}{2N} \Sigma^N_{i=1}(h_{\theta}(x^{(i)})-y^{(i)})^2$$

## Gradient Descent Concept

The goal of gradient descent is to find the $$\theta​$$ that could **minimize** the loss function $$J(\theta)​$$.

Formula:

$$
\theta \leftarrow \theta - \alpha \frac{\partial J(\theta)}{\partial \theta}
$$

* $$\leftarrow$$: means put the result that got from the righthand function to the lefthand ($$\theta$$).
* $$\alpha$$: represents learning rate. $$\alpha$$ **的大小决定的是每一步的步长**。
* $$\frac{\partial J(\theta)}{\partial\theta}$$: calculate the partial derivative for $$J(\theta)$$ to $$\theta$$ . $$\frac{\partial J(\theta)}{\partial\theta}$$ **的值决定的是下一步的方向**。

_Note: Here we use partial derivative to do the calculation because most of the time_ $$\theta$$ _is a vector instead of a scalar. we want to calculate_ $$\frac{\partial J(\theta_0 ... \theta_n)}{\partial \theta_j}$$.

## How does it work

首先我们先看 $$\theta$$ 只有一个值的情况，这时候 $$J(\theta)$$ 会是一条呈现出bowl shape的线。根据公式 $$\theta_0 \leftarrow \theta_0 - \alpha \frac{\partial J(\theta_0)}{\partial\theta_0}$$， 当 $$\theta$$ 在$$J(\theta)$$ 最小值的右侧时, $$\frac{\partial J(\theta)}{\partial\theta}$$ 作为这条切线是一个正数，所以这时候 $$\theta$$ 就会向左移动；而当 $$\theta$$ 在$$J(\theta)$$ 最小值的左侧时，这条切线是一个负数， $$\theta$$ 就会向右移动。在进行多次移动后，$$\frac{\partial J(\theta)}{\partial\theta}$$ 会逐渐趋近于0，直到找到 $$J(\theta)$$ 的最小值。

现在来看 $$\theta$$ 是一个vector的情况，假设是二维的话，我们就有 $$\theta_0 ,\ \theta_1$$ 。这个时候 $$J(\theta)$$ 会是一个呈现出bowl shape的面。而公式就变成了 $$\theta_j \leftarrow \theta_j - \alpha \frac{\partial J(\theta_0,\ \theta_1)}{\partial \theta_j} \ , \ j = 0, 1$$ 。这样的话每次移动的时候，我们考虑的是两个方向上的移动，简单理解可以说一个是向左右，一个是向前后。这样合起来我们就可以走向这个面上的任意一个位置。

## Mathematical Interpretation

$$
h_{\theta}(x^{(i)}) = \Sigma_{j=1}^n \theta_j x_j \ \  , \ \ \ \theta_j \leftarrow \theta_j - \alpha \frac{\partial J(\theta)}{\partial \theta_j}
$$

$$
J(\theta) = \frac{1}{2N} \Sigma_{i=1}^N(h_{\theta}(x^{(i)})-y^{(i)})^2
$$

To calculate the new $$\theta_j$$, we first need to find the derivative of $$J(\theta)$$ to $$\theta_j$$, and multiply it by $$\alpha$$ to get a value that tells model how to move for the next step. And then we use the current $$\theta_j$$ subtract this value to get the new $$\theta_j$$.

**How to make moves:**

$$\frac{\partial J(\theta)}{\partial \theta_j} = \frac{\partial }{\partial \theta_j}(\frac{1}{2N} \Sigma_{i=1}^N (h_{\theta}(x^{(i)})-y^{(i)})^2)$$

$$\ \ \ \ \ \ \ \ = \frac{1}{N} \Sigma_{i=1}^N (h_{\theta}(x^{(i)})-y^{(i)}) \cdot x_j^{(i)}$$

**Now we get new** $$\theta_j\ for\ j\ in\ 1\ to\ n$$**:**

$$\theta_j \leftarrow \theta_j - \alpha \frac{1}{N} \Sigma_{i=1}^N (h_{\theta}(x^{(i)})-y^{(i)}) \cdot x_j^{(i)}$$

By here we have updated $$\theta$$ once, and if we keep repeating this procedure, we can find the best $$\theta$$ that minimize $$J(\theta)$$.

## Learning Rate

在代码实现中，如果 $$\alpha$$ (learning rate) 选择的比较合适的话，run多次后 $$J(\theta)$$ 应该越来越趋近于0。如果我们发现 $$J(\theta)$$ 并没有随着run的次数增加而减小，而是**一直波动**的话，应该是 $$\alpha$$ **取值过大**所导致的。而如果我们发现 $$J(\theta)$$ 的**下降过于缓慢**的话，应该是 $$\alpha$$ **取值过小**所导致的。

**Tips**:

* 在多维度的情况下，我们可以对每个 $$\theta$$ 都单独指定一个 $$\alpha$$ ，但是这样做在实际操作中意义不大，并不能显著优化算法。
* 在实际操作中，我们一般来说并不需要随着梯度的变化设定一个自适应的(adaptive) $$\alpha$$ 。因为哪怕 $$\alpha$$ 的值在最开始是固定好的，但由于梯度的下降，我们移动时整体的步伐是会一同下降的，所以不会造成错过最优值的情况。

## Some Practical issue

**Feature scaling**: Some data need to be normalize before fitting models.

* Method A: $$x_j \leftarrow \frac{x_j}{max(x_j) - min(x_j)}$$ 将所有data的值都转换成0到1之间。
* Method B: $$x_j \leftarrow \frac{x_j - \bar{x}}{max(x_j) - min(x_j)}$$ 将所有data的值转换成在一个以(0, 0)为中心的圆形区间内的值。

**Batch**: In the previous example we use Full Batch Gradient Descent, however, sometimes in deep learning we might need to use Mini-Batch Gradient Descent or SGD(stochastic gradient descent).

## About Local Minimum

有时候在复杂的问题中，我们找到的最优值有可能是 local minimum 而不是 global minimum. 我们可以通过几种方法来解决这个问题:

* 首先当然是尽量避免使 loss function 存在 local minimum。
* 如果无法避免的话，我们也可以通过随机采样，给定不同的随机值，调整 $$\alpha$$ ，或使用 adaptive $$\alpha$$, 或者变异等方式来解决。
