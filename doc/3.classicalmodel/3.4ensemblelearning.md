# 3.4 Ensemble Learning

之前讲的决策树都只是使用单一的一棵树去做 classification 或者 regression。但现在在实际操作中，单独去使用一棵树的情况已经很少了。

机器学习中的error的主要原因就是 Bias 和 Variance (以打靶的那幅图作为例子的话 Bias 就是指瞄准的准心不准，而 Variance 就是指打的不准，每次打的点都很分散)，**集成学习的好处就是可以有效的减小 Variance**。

## Bagging

Bagging 是 bootstrap and aggregating 的缩写。

* **Bootstrap**: 从原本的 training dataset 里做放回式采样（每次抽出和原数据集一样多的样本），重复 $$K$$ 次，得到 $$K$$ 个新的 training dataset。这么做的目的是减小噪声的影响。作用是由于原始数据集里可能存在一些噪声，很多时候机器学习的模型会因为对这些噪声的 overfitting 而影响模型的性能。所以 bootstrap 这个做法能很好的减小噪声的影响 (variance)。
* **Aggregating**: 让每个根据新样本做出的模型进行投票，得票高的就作为最终结果。

由于最后统计的投票结果是直接相加求均值，所以这个方法其实是默认每个弱分类器对于最终结果的影响 (它们的权重) 是相等的。

**Bagging 的一个典型应用就是 Random Forest。**

Random forest 其实就是 Bagging with CART。通过多次放回式采样建立多个弱分类器。然后在最后决定最终值的时候让每个弱分类器进行投票，最终结果就是得票数高的结果：

计算投票结果的均值：$$F(x^{(i)}) = \frac{1}{K} \Sigma_{k=1}^K M_k(x^{(i)})$$

比如数据是 (0,1) 的分类，如果投票结果 $$F(x^{(i)}) <0.5$$ 就分类成 0， 如果 $$F(x^{(i)}) > 0.5$$ 就分类到 1。

## Boosting

Boosting 是指一种以多个弱分类器集合成一个强分类器的算法。像 AdaBoost, gradient boosting, xGBoost 都是 boosting 的方式。

这里我们以 AdaBoost (Adaptive Boosting) 为例子，假设我们现在有 $$n$$ 个数据:

$$D=\{(x^{(1)}, y^{(1)}), (x^{(2)}, y^{(2)}), ... ,(x^{(N)}, y^{(N)}) \}$$

$$x^{(i)} \in R^n \ , \ \ y \in \{+1, -1\}$$

AdaBoost 里会涉及两个权重：

* 每个数据 $$x^{(i)}$$ 的权重 $$w^{(i)} \in R$$&#x20;
* 每个弱分类器 $$G_k(x)$$ 的权重 $$\alpha_k$$
*   **Initialization - the weight of data at begining**

    先对数据集中的每个数据设定一个初始化权重，可以用均值让它们的初始权重相同。这里的设定是先假设数据集中每个点对模型都是同样重要的。

    $$w = (w^{(1)}, w^{(2)}, w^{(3)}, ... , w^{(N)})$$

    $$w^{(i)} = \frac{1}{N} \ \ , \ \ i = 1,2,...,N$$
*   **Updating** $$\alpha_k$$ **- the weight of weak classifier** $$k$$

    设置 $$k$$ 个弱分类器 (weak classifier) $$G_k(x)$$ for $$k = 0, 1,2,...,K$$

    计算每个弱分类器 $$G_k(x)$$ 的错误率 (error):

    $$e_k = \Sigma_i w^{(i)} I(G_k(x^{(i)}) \ne y^{(i)}) \ \ , \ \ \left \{ \ \begin{array}{} I(True) = 1 \\ I(False) = 0 \end{array} \right.$$

    然后根据这个弱分类器的错误率 $$e_k$$ 算出对应的弱分类器 $$G_k(x)$$ 的权重 $$\alpha_k$$:

    $$\alpha_k = \frac{1}{2} ln(\frac{1-e_k}{e_k})$$

    一个弱分类器的 error 越小，它的权重 $$\alpha_k$$ 越大。

    到这一步，我们的第一个弱分类器已经完成了，并且得出了这个弱分类器的权重。
*   **Updating** $$w_k$$ **- the weight of data at round** $$k$$

    在做完第一个弱分类器后，得到了第一个弱分类器的权重，现在就要根据这个弱分类器的权重 $$\alpha_k$$ 设定下一轮每一个数据的权重 $$w_{k+1}$$。

    重点对上一轮被分错的数据进行权重的调整，分错了的数据权重增加，分对了的数据权重减小：

    $$w_{k+1}^{(i)} = \frac{w_k^{(i)} exp(- \alpha_k \cdot y^{(i)} G_k(x^{(i)}))}{Z_k} \ \ , \ \ \ Z_k = \Sigma_{i=1}^N w_k^{(i)} exp(- \alpha_k \cdot G_k(x^{(i)})$$

    * $$y^{(i)} G_k(x^{(i)})$$ 表示第 $$i$$ 个数据的真实值 $$y^{(i)}$$ 乘以弱分类器 $$G_k$$ 对它的预测值 $$G_k(x^{(i)})$$。如果预测对了就是$$+1$$，如果预测错了就是$$-1$$。
    * 分子算出来的是调整过后的权重，这个 $$Z_k$$ 存在的目的只是做 normalization 用的，就是为了让所有数据的权重加起来的时候为1。

    现在根据第一个弱分类器的结果，我们得出了第二轮每一个数据的权重，然后开始做第二个弱分类器。做完第二个分类器，算出第二个弱分类器的权重，就可以求出第三轮数据的权重...etc.
*   **Final classification**

    在做完第 $$k$$ 个弱分类器后，我们就有了每一个弱分类器 $$G_k(x^{(i)})$$ 和它的权重 $$\alpha_k$$。

    在做最后的预测时，我们把每一个数据 $$x^{(i)}$$ 分别带入到每一个弱分类器 $$G_k(x^{(i)})$$ 中，然后根据权重对它们进行加和；这样就得到了最后的预测结果：

    $$f(x^{(i)}) = \Sigma_{k=1}^K \alpha_k G_k(x^{(i)})$$

    如果是 classification 的问题那就用一个$$sign$$ 函数：

    $$F(x^{(i)}) = sign (f(x^{(i)})) \ \ , \ \ \ \left \{ \ \begin{array}{lll}sign(f(x^{(i)})) > 0, F(x^{(i)}) = 1 \\ sign(f(x^{(i)})) < 0, F(x^{(i)}) = -1 \end{array} \right.$$

    如果 $$sign(f(x^{(i)})) = 0$$ 那就随便分哪边都行。

**最终的结果是通过集成之前所有的分类情况，再进行投票决定最终结果。所以绝对不是说最后一个 classifier 就是最好的。**

## Difference

* **Bagging：**
  * 通过多次放回式采样建立多个分类器，每个分类器得出一个结果，然后对所有的结果相加求均值。
  * 采好样之后每个分类器都是独立的，所以可以并行处理。
  * 每个分类器对于最终结果的影响 (它们的权重) 都是一样的。
* **Boosting：**
  * 按顺序调整每个分类器的权重，然后不断更新数据权重，再建立新的个分类器。
  * 每个分类器都会受到前面的分类器的影响，所以得一个一个来建。
  * 每个分类器对于最终结果的影响 (它们的权重) 是不一样的。

## GBDT - Gradient Boosting Decision Tree

In gradient boosting, we aim to fit residual of previous weak classifiers。所以我们想学习到一个 $$h(x)$$ 使下一轮对于数据的预测值更加接近于真实值：

$$F_{m+1}(x^{(i)}) = F_{m}(x^{(i)}) + h(x^{(i)}) = y^{(i)}$$

也就是要 minimize the expected value of the loss function：

$$F_m(x) = F_{m-1}(x) + argmin_{R_m \in H}\ \Sigma_{i=1}^N L(y^{(i)}, F_{m-1}(x^{(i)}) + h_m(x^{(i)}))$$

For $$m = 1,2,...,M$$, calculate pseudo-residuals training on $$\{x^{(i)}, r_m^{(i)}\} \ \ i = 1,2,...,N$$

​ $$r_m^{(i)} = -[\frac{\partial L(y^{(i)}, F(x^{(i)}))}{\partial F(x^{(i)})}] \ \ , \ \ F(x) = F_{m-1}(x)$$

$$r_m^{(i)}$$ is the residual of data $$x^{(i)}$$ given $$F_{m-1}(x^{(i)})$$，也就是通过求函数 $$F(x)$$ 对距离函数 $$L(y, F(x))$$ 的导数。

**如果我们用CART作为例子：**

在通过 CART 做 grdient boosting 的时候，我们是通过建立第一个决策树，然后得到了每个数据的预测值，这时候我们直接计算它们和真实数据之间的误差得到 residual $$r_m^{(i)}$$ 。

我们最开始学习的数据是：$$D=\{(x^{(1)}, y^{(1)}), (x^{(2)}, y^{(2)}), ... ,(x^{(N)}, y^{(N)}) \}​$$，但是在做完第一棵树之后我们会得到每个数据的预测值，然后算出 $$r_m^{(i)}​$$。然后接下来我们做的其实是 learn a new CART (with best $$j, s​$$) to fit $$r_m^{(i)}​$$。这时候用的数据是：$$D=\{(x^{(1)}, r_m^{(1)}), (x^{(2)}, r_m^{(2)}), ... ,(x^{(N)}, r_m^{(N)}) \}​$$。这个新的决策树其实在做的事情是通过第一棵树得到的 $$r_m^{(i)}​$$ 来学习一个新的决策树。这个新的决策树在每一个 leaf node 里再找到一个 $$C_{mj}​$$ 使这个区域里的这些数据的 residual 更小：

​ $$C_{mj} = argmin_c\ \Sigma_{x \in R_{(m,j)}} L(y^{(i)}, F_{m-1}(x^{(i)}) + c)$$

然后把这个新学到的决策树添加进之前的树里：

​ $$F_m(x) = F_{m-1}(x) + \Sigma_{j=1}^{J} \ C_{mj} I(x \in R(m,j))$$

最终的决策树就是：

​ $$F_m(x) = \Sigma_{m=1}^M \Sigma_{j=1}^{Jm} \ C_{mj} I(x \in R(m,j))$$

**shrinkage**

在做GBDT的时候有时候我们会加上一个 Shrinkage ，减小拟合速度，因为我们并不需要一次调整就期望达到最接近的效果，所以减小拟合速度这样不容易错过最优结果：

​ $$F_m(x) = F_{m-1}(x) + \theta \ \Sigma_{j=1}^{J} \ C_{mj} I(x \in R(m,j))$$

这里面我们添加的 $$\theta$$ 就是shrinkage，usually $$\theta \in [0.001, 0.01]$$ to reduce the fitting speed。

## XGBoost

xgboost 核心道理就是 GBDT。只是里面加入了很多可以调整的东西，比如regulization 和 shrinkage。这个是目前很强大的一个算法，很多竞赛里面用的都是 xgboost 的包。

通常可能会比 Random Forest 结果要好。
