# 3.2 Naïve Bayes

## Concept

和 Bayes 理论一样，当发生事件 $$X_1,...,X_n$$ 时，会发生事件 $$Y$$ 的概率是：

$$P(Y|X_1,...,X_n) = \frac{P(X_1,...,X_n|Y) P(Y)}{P(X_1,...,X_n)}$$

Naïve Bayes 的「naïve」在于假设：**在已知 $$Y$$ 的条件下**，各个 $$X_i$$ 相互独立（conditional independence），即 $$P(X_1,...,X_n|Y) = \prod_{i=1}^n P(X_i|Y)$$。所以：

$$P(Y|X_1,...,X_n) = \frac{\prod_{i=1}^n P(X_i|Y) \cdot P(Y)}{P(X_1,...,X_n)} \propto P(Y)\prod_{i=1}^n P(X_i|Y)$$

分母 $$P(X_1,...,X_n)$$ 对每个 $$Y$$ 都一样，所以比较哪个 $$Y$$ 概率最大时可以直接忽略它。

## Application

这个算法的假设很简单，有时候对于复杂问题的处理可能不如高级的算法好。但是也有些时候其实是够用了的，比如有的时候做垃圾邮件的分类就可以用到 Naïve Bayes。
