# 3.1 K-Nearest Neighbors

## Concept

KNN algorithm belongs to **supervised learning**, it is a non-parametric method used for classification and regression.

k **does not** have to be an odd number because the votes is not only based on number of votes but also based on distance(it would be the weight). But in practice we normally decide to use odd number to make things easier.

## The value of k:

* If k is too small, it might cause overfitting. The model would too complicated.
* If k is too large, it might cause underfitting. The model would be too simple.

KNN regression can be applied on time series problem.

## Distance

Human perception is the most important thing to consider.

$$d(A,B) = d(B,A)$$ Symmetry

$$d(A,A) = 0$$

$$d(A,B) = 0\ iff (if\ and\ only\ if) A=B$$

$$d(A,C) \le d(A,B) + d(B,C)$$

**Minkowski Distance (L-r norm)**

**Euclidean Distance (L-2 norm)**

$$dist(x,y)=\sqrt{\Sigma_{k=1}^d(x_k-y_k)^2}=||x-y||_2$$

**Manhattan Distance (L-1 norm)**

**Hamming Distance**

Use when all features are binary. When doing comparison, if two data are the same, the distance is 0, if not the same, the distance is 1.

**Cosine Similarity**

$$cos(x,y)=\frac{x^Ty}{||x||_2||y||_2}$$ 夹角越小越代表他们距离越近

**Edited Measure**

自定义一些情况，如果不同计1分，相同计0分
