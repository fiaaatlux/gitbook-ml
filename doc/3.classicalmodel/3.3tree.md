## Impurity Calculation

### 1. Information theory - Shannon Entropy

Shannon提出的理论，目前是理论相对最完善的。该理论判断 Impurity 的方式是求 Entropy (熵)。Engropy 代表混乱程度，我们做决策树的时候希望每个类的数据越纯净越好，也就是 Entropy 越小越好。

$$f(x) = -log\ P(x)$$

$$Entropy(x)=Ex[H(x)] \Rightarrow \begin{array}{}\Sigma_x P(x)f(x) \\ \int_x P(x)f(x) \end{array}$$

Information Gain: Gain(A, i) = $$Engropy(A) - \Sigma_i \frac{|A_i|}{|A|} Entropy(A_i)$$

Entropy 的范围是 0 - 1 之间

### 2. Gini Index

CART 使用的就是 Gini Index，计算起来不算麻烦，也能手算。

$$Gini(t) = 1 - \Sigma_j [P(j|t)]^2$$

Information Gain: $$Gini_{split} = \Sigma_{i=1}^k \frac{n_i}{n} Gini(i)$$

Gini 的范围是 0 - 0.5 之间

### 3. Misclassification Error

计算起来最简单

$$Error(t) = 1 - max P(i|t)$$

Missclassification Error 的范围是 0 - 0.5 之间

## CART

CART 是 classification and regression tree 的缩写。是一种比较传统的机器学习算法。

**在做 CART 的时候，我们要做的就是一个一个的二分类问题，找到 best variable** $$x_j$$ **和 cut point** $$s$$ **来 minimize loss function**:

$$Loss = min_{(j, s)}[min\ L(y^{(i)}, C_1) + min\ L(y^{(i)}, C_2)]$$

$$\ \ \ \ \ \ \ \ \ \ \ \ \ \ where \ \ C_m = avg(y_i | x_i \in R_m)$$

$$L$$ 代表距离函数，定义为 L-1 (绝对值)，L-2 (平方和)，L-p ()距离都是可以的。

在进行 Regression 的时候和 classification 一样也是将数据进行划分。然后计算预测值和实际值之间的距离。

现在我们用 L-2 距离 (Euclidean distance), we can rewrite the loss function by:

$$Loss = min[min \Sigma_{x \in R_1(j,s)}(y^{(i)} - c_1)^2 + min \Sigma_{x \in R_2(j,s)}(y^{(i)} - c_2)^2]$$

$$where \left \{ \ \begin{array}{lll} R_1(j,s) = \{x | x_j \le s \} \\ R_2(j,s) = \{x | x_j > s \} \\ C_m = \frac{1}{N_m} \Sigma_{x \in R_m(j,s)} y^{(i)} \ \ , \ m=1,2 \end{array} \right.​$$

CART 每次选择一个最好的 variable $$x_j$$ 和 cut point $$s$$ 把数据切割成2个部分，然后在每一个子节点继续选择一个最好的 variable $$x_j$$ 和 cut point $$s$$ 再把数据切割成2个部分，直到该区域的 loss 为 0，或者没有更多的 variable 可以用来继续划分为止。

最终的树就是：

$$f(x) = \Sigma_{m=1}^M C_m I(x \in R_m)$$
