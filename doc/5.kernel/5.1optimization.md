# 5.1 Function Optimization & KKTCondition

## Optimization

其实所有的算法中，我们说优化，主要就是跟 loss function $$J(\theta)$$ 有关。通过 minimize loss 来起到优化算法的效果。之前讲的内容里是没有限制条件的优化 (Unconstrained Optimization)，而今天要讲的有限制条件的优化。

现在我们假设 $$f(X)$$ 是一个 loss function，我们要 minimize 它：

$$
\left \{
\begin{array}{lll}
min\ f(X) \\
s.t. h(X) = 0 \\
s.t.\ g(X) \le 0
\end{array}
\right.
$$

比如上面这个就是一个有条件的优化，在保证 $$g(X) \le 0$$ 的情况下去 minimize $$f(X)$$。

## Unconstrained Optimization

首先无条件优化的时候我们的操作方式很简单，就是之前讲的，对 loss function 求导数，当它的导数等于 $$0$$ 的时候就是最优值。

比如给定一个 loss function $$f(X) = X^2$$。我们的目的是 $$\left \{\begin{array}{lll}min\ f(X) \end{array} \right. , \ \ x \in R$$

那 $$X^2$$ 的导数就是 $$2X$$，也就是当 $$2X = 0 \Rightarrow X = 0$$ 的时候我们得到最优值。

## Equility Constrained Optimization

现在来看加了限制条件的优化怎么操作。比如我们现在举个例子：

$$
\left \{
\begin{array}{lll}
min\ f(X) = x_1 + x_2 \\
s.t.\ h(X) = x_1^2 + x_2^2 -2 = 0
\end{array}
\right.
$$

这两个条件用几何的方式理解就是，第一个条件可以画出很多条平行的直线，第二个是一个圆。

现在比如我们从一个点 $$x_F$$ 开始慢慢移动，首先我们移动的条件是必须得沿着这个圆的线上去移动，也就是说 $$\Delta x$$ 要满足条件：$$h(x_F + \mu\ \Delta x) = 0$$。这里面 $$\Delta x$$ 是一个趋于无穷小的数，而 $$\mu$$ 是一个常数，代表着移动多少个 $$\Delta x$$ 。移动完了以后我们需要这个点依然在这个圆上，而这个圆就叫做 Feasible Region。

这个点在移动后除了必须要在 Feasible Region 上以外，我们同时希望它每次移动都是朝着梯度下降的方向移动的，也就是：$$f(x_F + \mu \Delta x) < f(x_F)$$。

而我们现在要 minimize $$f(X)$$， 所以就是要求 $$f(X)$$ **的负梯度，**&#x90A3;首先我们来求它的正梯度，也就是对 $$f(X)$$ 求导数：

$$
\nabla_X f(X) =
\left[ \begin{array}{ccc}\frac{\partial (x_1+ x_2)}{\partial x_1} \\ \frac{\partial (x_1 + x_2)}{\partial x_2}
\end{array} \right]
= \left[ \begin{array}{ccc} 1 \\ 1 \end{array} \right]
$$

这样我们就得到了 $$f(X)$$ 的正梯度，那它的负梯度就是：$$\left[ \begin{array}{ccc} -1 \\ -1 \end{array} \right]$$

所以我们希望 $$\Delta x$$ 移动的方向和 $$f(X)$$ 的负梯度的方向基本是一致的 (总不能是相反的)，也就是说：$$\Delta x \cdot (-\nabla_X f(X)) > 0$$

_\*Note: 两个 vector 相乘如果大于_ $$0$$ _就表示他们的方向基本是一致的 (这两个 vector 组成一个锐角)；如果等于_ $$0$$ _就表示他们的方向呈 90 度；如果小于_ $$0$$ _就表示他们的方向相反 (这两个 vector 组成一个钝角)。_

然后我们再求一下 $$h(X)$$ **的梯度**，也就是：

$$
\nabla_X h(X) =
\left[ \begin{array}{ccc}\frac{\partial (x_1^2 + x_2^2 - 2)}{\partial x_1} \\ \frac{\partial (x_1^2 + x_2^2 - 2)}{\partial x_2}
\end{array} \right]
= \left[ \begin{array}{ccc} 2x_1 \\ 2x_2 \end{array} \right]
$$

现在我们随便取这个圆上的一个点 $$x_F$$，然后开始移动，每次移动：

$$
\left \{
\begin{array}{lll}
\Delta x \cdot (-\nabla_X f(X)) > 0 \\
x_F \leftarrow x_F + \mu \Delta x
\end{array}
\right.
$$

直到 $$\Delta x \cdot (-\nabla_X f(x_F)) = 0$$ ，也就是 $$\Delta x \bot \nabla_X h(x_F) \Rightarrow \Delta x \cdot \nabla_X h(x_F)=0$$ 。

也就是说 $$-\nabla_X f(x_F)$$ 和 $$\nabla_X h(x_F)$$ 这两个梯度是平行并且朝同一个方向的，这样的话我们就把刚才的两个条件合并在一起了。它们两个之间其实只是有一个常数的关系，也就可以写成是： $$-\nabla_X f(x_F) = \mu \ \nabla_X h(x_F)$$

\*Note：这里我们求的是 minimize $$f(X)$$ 所以 $$-\nabla_X f(x_F) = \mu \ \nabla_X h(x_F)$$；如果是 maximize $$f(X)$$ 的话就是 $$\nabla_X f(x_F) = \mu \ \nabla_X h(x_F)$$。

## Lagrange

现在我们要做的就是求出最优值 $$x^*$$，满足条件：$$-\nabla_X f(x^*) = \mu \ \nabla_X h(x^*)$$

我们根据刚才的推导，可以构造出一个拉格朗日函数来表示：

$$
L(X, \mu) = f(X) + \mu h(X)
$$

这里的 $$\mu$$ 就是 Lagrange multiplier，满足条件 $$\mu > 0$$，这个函数叫做 Lagrange function。

这里面。

这个拉格朗日函数要满足的条件就是：

$$
\nabla_X L(X, \mu) = 0
$$

所以现在我们先对 $$X$$ 进行求导：

$$
\begin{eqnarray*}
\frac{\partial L}{\partial X} = 0 \ \ \ &\Rightarrow& \ \ \ \nabla_X f(X) + \mu \ \nabla_X h(X) = 0 \\
&\Rightarrow& -\nabla_X f(X) = \mu \ \nabla_X h(X)
\end{eqnarray*}
$$

这个和刚才通过几何的方式求出的公式是一样的。

然后对 $$\mu​$$ 进行求导：

$$
\begin{eqnarray*}
\frac{\partial L}{\partial \mu} = 0 \ \ \ &\Rightarrow& \ \ \ h(X) = 0
\end{eqnarray*}
$$

_如果用刚才的例子的话我们可以将这个拉格朗日函数求出来：_

$$
L(X,\mu) = (x_1 + x_2) + \mu (x_1^2 + x_2^2 -2) \\
\frac{\partial L}{\partial X} = \left[\begin{array}{}1 + 2 \mu x_1 \\ 1 + 2 \mu x_2 \end{array} \right] = 0 \ \ \ \ \Rightarrow \ \ \ X = \left[\begin{array}{}-\frac{1}{2\mu} \\ -\frac{1}{2\mu} \end{array} \right] \\
\frac{\partial L}{\partial \mu} = x_1^2 + x_2^2 -2 = 0 \\
(-\frac{1}{2\mu})^2 + (-\frac{1}{2\mu})^2 = 2 \ \ \ \ \Rightarrow \ \ \  \mu = \frac{1}{2} \\
X = \left[\begin{array}{}-\frac{1}{2\mu} \\ -\frac{1}{2\mu} \end{array} \right] = \left[\begin{array}{}-1 \\ -1 \end{array} \right]
$$

_通过这样的方式我们就找到了_ $$X$$ _的最优值。_

## Inequality Constrained Optimization

刚刚上面说的是限制条件是等式的情况下的优化，现在来说不等式的优化。

**Case 1:**

$$
\left \{
\begin{array}{lll}
min\ f(X) = x_1^2 + x_2^2 \\
s.t.\ g(X) = x_1^2 + x_2^2 -1 \le 0
\end{array}
\right.
$$

上面这个情况我们可以求出 $$\nabla_X f(X) = \left[\begin{array}{}2x_1 \\ 2x_2 \end{array} \right] = 0 \ \ \ \Rightarrow \ \ \ X = \left[\begin{array}{}0 \\ 0 \end{array} \right]$$

这个时候 $$f(X)$$ 的全局最优值刚好是满足我们的限制条件的，所以也不需要另外做什么了。

**Case 2:**

$$
\left \{
\begin{array}{lll}
min\ f(X) = (x_1 - 2)^2 + (x_2 - 2)^2 \\
s.t.\ g(X) = x_1^2 + x_2^2 -1 \le 0
\end{array}
\right.
$$

因为这个时候 $$f(X)$$ 的全局最优值是在 $$g(X)$$ 限制条件外的，所以最接近全局最优值的解应该是在 $$g(X)$$ 的边缘上的。也就是说我们的限制条件其实就相当于是：$$g(X) = x_1^2 + x_2^2 -1 = 0$$。

## KKT Condition

Karush-Kuhn-Tuker Condition，用来解决不等式情况下的 Optimization。

对于刚才不等式情况下的两个 Case，我们其实依然可以通过构建一个拉格朗日函数表示出来：

$$
L(X, \lambda) = f(x) + \lambda g(X)
$$

这个函数在满足几个条件 (KKT Condition) 的时候能求出最优值：

$$
\left \{\begin{array}{lll}
\nabla_X L(X^*, \lambda^*) = 0 \\ 
\lambda^* \ge 0 \\
\lambda^* g(X^*) = 0 \\
g(x^*) \le 0
\end{array} \right.
$$

如果是 case 1，那么 $$\lambda = 0$$，表示全局最优值在限制条件内。 如果是 case 2，那么 $$g(X^*) = 0$$，表示全局最优值在限制条件外，最接近全局最优值的解在 $$g(X)$$ 的边缘上。

## Conclusion

现在我们可以把刚才等式的优化和不等式的优化综合来看，变成一个更 general 的形式。

首先我们的要求是：

$$
\left \{
\begin{array}{lll}
min\ f(X) \\
s.t.\ h_i(X) = 0 \ \ , \ i = 1,2...l \\
s.t.\ g_j(X) \le 0 \ \ , \ j = 1,2...m \\
\end{array}
\right.
$$

然后我们构建一个拉格朗日函数：

$$
L(X, \mu, \lambda) = f(X) + \Sigma_{i=1}^l \ \mu_i h_i(X) + \Sigma_{j=1}^m \ \lambda_j g_j(X)
$$

要求最优值的话就需要满足的条件是：

$$
\left \{\begin{array}{lll} 
\frac{\partial L}{\partial X} = 0 \\ 
\frac{\partial L}{\partial \mu} = 0 \\ 
\frac{\partial L}{\partial \lambda} = 0 \\
\end{array} \right.
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ 
\left \{\begin{array}{lll} 
\mu_i^* \ge 0 \\
\lambda_j^* \ge 0 \\
\lambda_j^*g_j(x^*) = 0 \\
g_j(x^*) \le 0
\end{array} \right.
$$
