# 5.2 Support Vector Machines

## Concept

SVM 本质仍然是一个线性函数的优化，只是因为有一些在二维空间不可分的点，需要去映射到高维空间，这样就变得可分了。

所以需要在高维空间中找到一个面 ，这个面能使要划分的两个类别之间的 margin 最大 (boundary with maximum margin)。

因为要做的事情是找到最大的 margin，所以在 margin 上的数据是最重要的，这些数据就被称为 Support Vector；而不在 margin 上的数据的权重就被置为 0。

## Hyperplane

刚才所说的那个面 (hyperplane) 可以通过一个函数来表示：

$$
w^T X + b
$$

如果 $$Y (w^T X + b) > 0$$ 就表示分类是正确的，如果 $$Y (w^T X + b) < 0$$ 就表示分类是错误的 (分类的的数据的 $$Y$$ 是 $$\{-1,+1\}$$)。

这个最大 margin 之间的距离就是 $$\frac{2}{||w||}$$。

所以现在可以把求这个最大 margin 的问题写成一个 optimization 的问题：

$$
\left \{
\begin{array}{lll}
max\ \frac{2}{||w||} \\
s.t. Y (w^T X + b) \ge 1
\end{array}
\right.
$$

或者也可以把这个写成我们之前熟悉的的表达方式 (和上面是一样的)：

$$
\left \{
\begin{array}{lll}
min\ \frac{1}{2}||w||^2 \\
s.t. 1 - Y (w^T X + b) \le 0
\end{array}
\right.
$$

SVM 的本质其实就是要求上面这个 optimization 的问题。

## Dual form of Lagrange multiplier

现在就可以通过之前讲的拉格朗日函数的方式来求这个问题，首先构造一个拉格朗日函数：

$$
L = \underbrace{min}_{w,b}\ \underbrace{max}_{\alpha_i}\ \frac{1}{2}||w||^2 + \Sigma_{i=1}^N \alpha_i [1 - y_i (w x_i + b)]
$$

对于这个拉格朗日函数可以变化一下格式：

$$
L = \underbrace{max}_{\alpha_i}\ (\underbrace{min}_{w,b}\ \frac{1}{2}||w||^2 + \Sigma_{i=1}^N \alpha_i [1 - y_i (w x_i + b)])
$$

**Step 1: 首先可以解括号里面** $$min(w,b)$$ **的部分**

这里把括号里面的部分再写成拉格朗日函数的形式：

$$
L = \underbrace{min}_{w,b}\ \frac{1}{2}||w||^2 + \Sigma_{i=1}^N \alpha_i [1 - y_i (w x_i + b)]
$$

然后去解这个拉格朗日函数得到：

$$\frac{\partial L}{\partial w} = 0 \ \ \ \ \Rightarrow \ \ \ \ w = \Sigma_i \alpha_i y_i x_i$$

$$\frac{\partial L}{\partial b} = 0 \ \ \ \ \Rightarrow \ \ \ \ \Sigma_i \alpha_i y_i = 0$$

**Step 2: 将这个解带入整个拉格朗日函数**

$$
\begin{eqnarray*}
L &=& \frac{1}{2}(\Sigma_i \alpha_i y_i x_i)^T (\Sigma_j \alpha_j y_j x_j) + \Sigma_{i=1}^N \alpha_i [1 - y_i (\Sigma_j \alpha_j y_j x_j x_i + b)] \\
&=& \frac{1}{2}(\Sigma_i \Sigma_j \alpha_i \alpha_j y_i y_j x_i x_j) + \Sigma_i \alpha_i - \Sigma_i \Sigma_j \alpha_i \alpha_j y_i y_j x_i x_j + \Sigma_i \alpha_i y_i b \\
&=& \Sigma_i \alpha_i - \frac{1}{2}\Sigma_i \Sigma_j \alpha_i \alpha_j y_i y_j x_i x_j + \Sigma_i \alpha_i y_i b
\end{eqnarray*}
$$

**Step 3: 现在就可以得出最终的拉格朗日函数表达式**

把刚刚拉格朗日函数中的 $$w,b$$ 的部分替换掉；然后因为 $$\Sigma_i \alpha_i y_i = 0$$，所以最后我们刚才的拉格朗日函数可以写成：

$$
\begin{array}{lll}
L = \underbrace{max}_{\alpha_i}\ \ \Sigma_i \alpha_i - \frac{1}{2}\Sigma_i \Sigma_j \alpha_i \alpha_j y_i y_j x_i x_j \ \ , \ \ \ \ (i,j = 1,2...N) \\
s.t.
\left \{\begin{array}{lll} 
\alpha_i \ge 0 \\
\Sigma_i \alpha_i y_i = 0
\end{array} \right.
\end{array}
$$

**Final Step: 到这里就可以求出最终的解**

首先通过上面的函数求出 $$\alpha^* = (\alpha_1^*, \alpha_2^*, ... , \alpha_N^*)$$

然后通过 $$\alpha^*$$ 求出 $$w^* = \Sigma_i \alpha_i^* y_i x_i$$

最后再通过 $$\alpha^*$$ 和 $$w^*$$ 求出 $$b^*$$，所有在 margin 上的点都满足条件 $$y_i(wx_i + b -1) = 0$$；而不在 margin 上的点则是 $$\alpha_i = 0$$。

## Kernel

Kernel 的选择有很多种，比如：Linear Kernel，Polynomial Kernel，Radial Basis Function Kernel。刚刚我们在拉格朗日函数里举的例子就是简单的 Linear Kernel。在深度学习出来之后，现在研究 kernel 的人也不多了。
